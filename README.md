# Jeu de Nim v2

Petit jeu de Nim développé en Python, jouable en ligne de commande.

## Objectif

Le but du jeu est de retirer des objets dans les tas. Le joueur qui prend le dernier objet gagne la partie.

## Fonctionnalités

- Jeu à deux joueurs
- Mode avec configuration personnalisée des tas
- Interface console simple
- Possibilité de rejouer après chaque partie

## Lancement

Depuis le dossier du projet, exécutez :

```bash
python main.py
```

## Structure du projet

- `main.py` : point d'entrée du jeu
- `nim_logique.py` : logique du jeu et règles
- `nim_affichage.py` : affichage et interactions en console
